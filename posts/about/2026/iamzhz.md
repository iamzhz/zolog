# 浅浅介绍一下我和我对自己的想法
说来惭愧，我搞了这个博客网页，本来是想经常写写文字的，可惜时间并没有那么多，再加上假期时我懒懒的，这个网页上只一篇泛泛讨论正弦函数的代码实现的文章。当然，那篇文章也是为醋包饺子啦。

## 啥是 iamzhz
我在很多平台上的网名/id/nickname都是 iamzhz，这个名字是怎么来的呢？其实非常肤浅：我最初经常使用的昵称是 zhz，我姓名中每个字的汉语拼音的首字母，——直到我注册 GitHub。  

zhz 被另一位 GitHub 用户使用了，那我就必须再起一个呗。灵机一动，我加了一个 `I am` 前缀，就成了 iamzhz，注册成功~  

于是 iamzhz 这个 id 便让我沿用至今……  

## 我很菜
### 我很菜，但我不服
我目前是一个高中生，就读于河南一个小县城的一所破破烂烂的衡水式中学（跟真正的衡水可能差点？但也不妨碍我称它是衡水式中学）。  
准高一的时候，我经常看到网络里的一些中学生发起一些很好的开源项目，它们可能不算专业，可他们要比我优秀得多。每每看到这些东西，我心里顿生自卑之感：看看人家的技术力、执行力多么强大，比较起来我怎么什么都不会啊(｡•́︿•̀｡)。   

值得可幸的是，我可以找出大把的~~借口~~理由，以舒缓我的情绪：  
1. 人家是大城市的，有的中小学甚至都能每天回家，自然有时间学这些东西。这样来看，他们只是多了时间，并不是智力上的差别。也许等我高中毕业了，有时间了，我也会变得很强？  
2. 语文是面具？我的语文非常地差劲，虽说“人不可貌相”，但语言表达能力是会给人留下第一印象的。我是在说：会不会我看到的别人的优秀项目都是“假象”？其实他们没我想的那么厉害，而只是在语言上给人眼前一亮？  
（以上只是猜测）  

综上所述，我不服<(￣︶￣)>  

### 我不服，但我也会不开心
虽然我持有一些借口，但我菜是藏不掉的事实。我菜，故我经常犯错。  

在自己的仓库里想怎么犯错都行，  
但是但是，我给别人的项目提 issue/pr 时，偶尔在线上和其他人有过一点小小的交流时，我也犯错，尤其是别人先于我注意到我的错误时，我会瞬间觉得天塌了。(｡ŏ﹏ŏ)  

之后我一般会放下电脑，放下手机，抱着被子瘫卧在床上，目光呆滞，呼吸都不顺畅了，脑子里一遍一遍回放自己的愚蠢。就这样什么都不做。  

### 我会不开心，但我忘性大
没错，不开心也只是暂时的情绪，缓缓再坐起来，继续解决问题，也可以嘛~  

之后，我就忘了。再回看当初我出错的那个网页，我会更平静一点。就像我从来没犯过错一样。( ╹▽╹ )  

先这样吧(^～^;)ゞ
