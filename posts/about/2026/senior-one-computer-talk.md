# 高一：我在上铺听他们聊计算机
## 前言
升到高二，我们分班了，分别，本该是个叹息的时候。但我对我们班人没多大的情感，也就叹息不起来了。  
这可能是因为，班里经常调换座位，我在关系的处理非常差，连同学们都没认全，也没一个相互熟悉的人。  
但寝室没换过，他们 7 个人对于我可能是最大的情感连结了（即使同样不熟）。  

因为大家总喜欢在睡前说说话嘛（除了我），我也听了他们的讨论听了一年了，他们的气质语气我都熟记于心了。要离开了，心里很难不产生什么触动。  

大家讨论的很多事情，比如什么游戏啦，什么去哪里玩啦，什么校园里的情情爱爱啦，我都不爱听。  

我感兴趣的是，有关计算机的东西。这些东西也会偶尔出现在他们的讨论里，我的印象也十分地深刻。他们的其他讨论当然也很有趣，但就怪我不感兴趣嘛…  

然而……可悲的是，大家对计算机的理解可能不够，谈论中常常出现很荒谬的东西，下面我依靠我的记忆来复述一些这些讨论。  

我没有批评、嘲笑的意思，只是突然顿悟，原来如果我们不深入领会，会产生这么大的误差啊。  

## 三个对话

（下文中，C,S,M 指三位室友，I 是我）  

### 话题 1：指 `Python` 为 `C++`

初拿到高中必修《信息技术》课本，  
必修一是比较基础的 Python 教程；  
我的下铺摊开书看了看：怎么初中学完 C++ 现在还学啊……  

S：是吗？（摊开书）还真是……  

我：（悄悄对下铺）我们高中学的是 Python 啊……  

（下铺没听见，我果然还是小透明）  

### 话题 2：服务器是假象的概念
（讨论一个已经不再维护的单机游戏运行的可行性）  
C：如果我把那个游戏的安装包下载到手机上，再安装不就行了。  
S：它的网站已经没有了，你从哪里下？  
（接下来演化为讨论安装包再分发的可行性）  
M：你不用非要去它的网站下啊，你可以去其他地方……  
S：它的网站已经没有了。网络信息传递需要啥？电磁波。  
看事物要看本质，你的数据从哪里来，它的服务器通过电磁波传给你。实际上服务器是我们假想的概念……  
（省略更多奇奇怪怪的话）  
最起码也需要域名——  
所以其他地方没办法下载。  
（M和C沉默，我不知道他们是懒得说还是真的被说服了）  

### 话题 3：世界上没有二进制计算机
C：现在电脑都是十六进制，如果我发明一个二进制的电脑会怎么样？  
S：（默认“十六进制”的说法，说一些偏离技术的话）  
I：（忍不住了，悄悄伸头）班长~ 现在的电脑就是二进制的啊……  
C：不是十六进制的吗？  
S：（试图强行解释）用二进制存还不如十六进制存呢，二进制不浪费空间吗？  
I：（懵了）什么浪费空间？……但就是二进制的啊。  
S：那怎么压缩呢？  
I：什么压缩？（啊这……想到什么说什么吧）呃……压缩用压缩算法啊。  
S：什么是压缩算法？我问你，它的存在形式是什么？  
I：（还有这么问的？）（回忆初中计算机第一节老师对算法一词的定义，但想不起来了）……  
S：数据存放在哪里呢？  
I：（啊~这个我知道）固态硬盘是靠磁场方向辨识，机械硬盘是靠存储颗粒，内存是和……  
S：那为什么是二进制不是十六进制呢？
I：因为二进制信号在传递时只需要两个电平，十六进制太多不好识别……常用十六进制是因为一位十六进制数可以对应四个二进制数…  
（S，C 沉默了一段时间）  
M：这是谁的声音？  

## 最后

至于它们何处荒谬我就不再说了，因为我太笨了太懒了不想解释。(≧▽≦）  

我感觉挺有趣的，我发现，很多时候，大家都在激烈地讨论，在不经意间理直气壮地犯错。而我拥有着上帝视角，有能分辨是非的慧眼（^_________^至少在这些话题上），偷听着他们的话，却窝在上铺的角落里私自遐想。  

这是一件很好玩的事不是吗？  

我以人为镜地反思了一下，事物规律不能太依赖于自己的想象，也许想象很美好，现实中却有一个大坑。  

我从很早之前就有了一个习惯，没有足够的考据，没有十足的把握，就不开口发表意见（然而有时我还会犯错）。这可能是……我总是如此沉默的原因？  

（高情商：沉默是对真理的守护）  
（低情商：胆子小）
